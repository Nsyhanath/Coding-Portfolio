LEVEL 1-1 CLEARED

Twenty Questions

A guessing game where the computer tries to figure out what you're thinking of. Everything it knows is stored in a binary tree. When it guesses wrong, it asks you for a new question and adds it to the tree, so it actually gets smarter the more you play. You can save the tree to a file and load it back later.

Objectives Completed

  • Built my own Node and Tree structs, with recursive destructors to clean up memory
  • Adds new questions in the middle of a game without losing any branches
  • Saves and loads trees in two file formats using a recursive pre-order traversal
  • Command-line flags to load a saved game (-f) or show help (-h)

LEVEL 1-2 CLEARED

Sticks and Stones

A two-player take-away game based on the classic game of Nim. Players take turns removing stones from the piles, and whoever takes the last stone wins. You can also play against the computer, which uses the best possible strategy: it finds the nim sum by XORing every pile together and always makes the winning move when there is one.

Objectives Completed

  • Computer opponent that uses bitwise XOR to find the nim sum and the winning move
  • Random board setup with srand, so every game is different
  • Input validation, so you can't make an illegal move or take more stones than a pile has
  • Command-line flags to set the number of piles (-p) and stones (-s) and to turn on the computer opponent (-c)

WORLD 2-1 CLEARED

Multi-OS Network Infrastructure

My Unix home lab. I set up six different Unix systems as virtual machines in VMware and connected them to one internal domain, so one account can log in on any of them. I built every part myself, including the directory server, DNS and my own certificate authority. This was an academic project from February to May 2026.

Objectives Completed

  • Ran OpenBSD, FreeBSD, AlmaLinux, Ubuntu and OpenIndiana as virtual machines in VMware
  • Set up shared logins with OpenLDAP over TLS, connected to each OS through SSSD, NSS and ypldap
  • Created my own OpenSSL certificate authority to issue and revoke TLS certificates for LDAP, mail, nginx and a self-hosted GitLab
  • Ran BIND DNS for the internal domain
