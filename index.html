Twenty Questions

A guessing game where the computer tries to figure out what you're thinking of. The computer's knowledge is stored as a binary tree, and every time it guesses wrong it asks you for a new question and grafts it into the tree — so the game genuinely gets smarter the more you play it. Trees can be saved to disk and reloaded later.

  • Custom Node and Tree structs with recursive destructors for clean memory management
  • Live tree restructuring — new questions are inserted mid-game without losing branches
  • Save/load to two file formats via recursive pre-order traversal
  • Command-line flags for loading a saved game (-f) and help text (-h)

Sticks and Stones

A two-player take-away game (the classic game of Nim). Players take turns removing stones from a single pile, and whoever takes the last stone wins. The optional computer opponent plays the mathematically optimal strategy — it calculates the nim sum with an XOR across every pile and always moves to force a win when one exists.

  • Optimal AI using bitwise XOR to compute the nim sum and find the winning move
  • Randomized board generation with srand for a different game every run
  • Full input validation — no illegal moves, no over-drawing a pile
  • Configurable via CLI flags for piles (-p), stones (-s), and computer opponent (-c)
